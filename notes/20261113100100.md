core/fs.js parses only the YAML subset notes use: scalars (plain, single or double quoted, folded across lines), inline lists, and block lists of scalars or flat maps. Block scalars (| and >), anchors and nested maps are unsupported, and unknown keys are ignored. Serialisation writes plain scalars only when unambiguous and otherwise emits JSON strings, which are valid YAML double-quoted scalars, so other YAML readers and the azk CLI still parse the files. Notes produced by the old yaml library (single-quoted timestamps, `links: []`) are covered by a test using the existing note as a fixture.
