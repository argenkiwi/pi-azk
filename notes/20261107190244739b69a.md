Azk extension in Pi Coding Agent derives its embedding host URL from ctx.model.baseUrl and syncs dynamically on model_select and session_start events. Environment variables EMBEDDING_HOST and EMBEDDING_MODEL are kept in sync with process.env so subshells and CLI tools share the exact same endpoint. All embedding calls return null on connection failure rather than throwing, ensuring hybrid search and note reindexing gracefully degrade to SQLite FTS5 keyword matching when the local host or model is unavailable.
