The extension is plain ESM JavaScript with JSDoc types and no npm dependencies, because the Pi container (node:24-bookworm-slim) has no Deno and development now happens inside Pi. It relies on Node 24 built-ins (node:sqlite, fetch, node:crypto, node:test), so `engines.node` is >=24. Tool parameters are plain JSON Schema literals instead of typebox; this is unverified against Pi's own validator, so if Pi rejects them, add a tiny schema helper rather than a dependency. Note IDs have one-second resolution, so azk_create steps forward to find a free ID, otherwise rapid creates overwrite each other.
