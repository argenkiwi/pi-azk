The `npm test` script must use `node --test tests/*.test.js`, not `node --test tests/`. On Node 24.22.3, passing a bare directory `tests/` makes the runner try to resolve it as a module entry, throwing `Cannot find module '/workspace/tests'` and failing with `code: MODULE_NOT_FOUND` instead of discovering test files. A glob (`tests/*.test.js`) or running `node --test` with no args (default discovery) both work. All 17 tests live in tests/*.test.js and pass offline via mkdtemp + stubbed globalThis.fetch.
